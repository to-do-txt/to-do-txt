How to use to-do-txt

Your list is a plain text file. Each line is one task. Everything below is optional: use only what you need.

Adding a task

Type in the bar at the top and press Enter or Add. Today's date is stored automatically, unless the task starts with a priority.

Call mom due:tomorrow +family @phone

Priority

Put (A), (B) or (C) at the start of a line. (A) is the most urgent. Sort by Priority in the View menu to see them first.

Projects and contexts

Projects start with + and group tasks by what they belong to, like a house or a job: +home, +work.

Contexts start with @ and describe where or how you can do a task, like a place or a tool: @phone, @errands.

Click any project or context in the sidebar to show only those tasks.

Due dates

Add due: followed by a date or a shortcut:

  • due:2026-10-15 a specific date
  • due:today or due:tomorrow
  • due:friday the next Friday
  • due:3d three days from today, due:2w two weeks from today

Due dates feed the Date Dashboard in the sidebar: Overdue, Today, Upcoming and No Due Date.

Working with tasks

  • Finish a task: tick its checkbox. It's marked done with the date you finished it.
  • Edit a task: click its text. Press Tab to complete a +project or @context while typing.
  • Clean up: Sweep Done (View menu) moves finished tasks to the bottom of the list.
  • Links: write link:example.com and it shows as a clickable link.
  • Bulk edit: View menu → Bulk Edit edits the whole file as plain text.

Lists and saving

Each todo_NAME.txt file is a separate list. Manage them under File Manager in the sidebar.

Pick where your list is saved with the icons in the sidebar: Dropbox, Google Drive or a Local folder. The status line under the title shows Saving, Saved or Offline.
